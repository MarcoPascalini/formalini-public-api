# Build with Formalini

Developers, consultants and agencies can build applications for their own customers using the Formalini API. The open-source SDKs and examples are separate from paid use of the hosted service.

The project brief describes a future Developer Partner Program for eligible client referrals. No public enrollment route or governing terms were verified during this build. Program terms will govern eligibility and commission if the program is launched. Do not add referral identifiers to SDK traffic.
