# What developers can build

Formalini exposes a document-to-structured-data step for applications. Build a narrow integration first: upload a supported page image, inspect extracted fields, correct uncertain values, then pass approved data to your own system.

## Accounts payable

Read invoice fields and line items, review them, and hand approved values to an accounting workflow. Keep the invoice and its extracted values linked by document ID.

## Receipts and forms

Extract merchant, date and total from receipts or configured fields from completed forms. Validate values against your own application rules before use.

## Internal tools

Replace manual copying from scanned paperwork into a line-of-business application. Use webhook events to begin downstream processing after review, and verify each event signature.

## Specialist applications

Developers can use the same API primitives for document intake in logistics, legal or healthcare products. Domain-specific policy, review rules and compliance remain the application's responsibility; this repository does not provide a complete sector solution.
