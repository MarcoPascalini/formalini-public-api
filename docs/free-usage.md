# Free API usage

The [current public pricing page](https://formalini.com/pricing) lists a Free plan with 100 AI credits per month, 100 MB document storage and one document per day. It defines one AI credit as one page read. These values can change; check the pricing page and your account before planning capacity.

The [API docs](https://formalini.com/docs) say upload can return 402 when credits, storage or the daily allowance is exhausted. The account application manages usage and billing. SDKs report the API error; they do not purchase credits or change plans. The pricing page describes paid plans and one-off credit packs for additional usage.
