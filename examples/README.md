# Examples

- [PDF to JSON](pdf-to-json/README.md): render PDF pages to images before API upload.
- [Invoice to JSON](invoice-to-json/README.md): upload a page image and inspect extracted fields.
- [Receipt to JSON](receipt-to-json/README.md): inspect merchant, date and total before expense use.
- [Form to JSON](form-to-json/README.md): select a template and validate named fields.
- [Image to JSON](image-to-json/README.md): submit a photo in a supported format.
- [Handwriting](handwriting-to-json/README.md): route uncertain readings for review.
- [Purchase order](purchase-order-to-json/README.md): compare extracted values with the source.
- [Custom schema](custom-schema/README.md): pass an existing template ID.
- [Correct extracted data](correct-extracted-data/README.md): update a field by name.
- [Workflow dispatch](workflow-dispatch/README.md): send a documented event to subscribed webhooks.

All examples use the [published API contract](https://formalini.com/docs). Keep document contents and API keys out of source control.
