# Examples

- [PDF to JSON](pdf-to-json/README.md): render PDF pages to images before API upload.
- [Invoice to JSON](invoice-to-json/README.md): upload a page image and inspect extracted fields.
- [Correct extracted data](correct-extracted-data/README.md): update a field by name.
- [Workflow dispatch](workflow-dispatch/README.md): send a documented event to subscribed webhooks.

All examples use the [published API contract](https://formalini.com/docs). Keep document contents and API keys out of source control.
